# AIoT Explorer

A learning path for AIoT。

AIoT Explorer 是一条由 AI 协助整理、人工审核的实践型学习路径。

它带你从 BLE、Radar、ToF 等真实数据出发，理解数据如何被采集、处理、融合，并最终转化为设备行为与智能应用。

## 学习路径

学习内容包括：

```text
阶段1
    BLE：在发现、广播和连接过程中梳理流程与方法
    Radar：从电磁波到 I/Q 数据，从I/Q变化到目标特征判断
    ToF：从一束光到距离、从距离到深度图和应用
    ML、TinyML & Edge AI：从初始数据开始，探索 TinyML、边缘 AI 与 GenAI 的融合应用。

阶段2 
    Wi-Fi CSI：环境感知与行为识别
    Sensor Fusion：多传感器数据融合
    Security：设备认证、固件升级与数据保护

阶段3
    IoT Connectivity：Wi-Fi、MQTT、Matter 与 Mesh 网络
    Embedded Basics：MCU、OS、外设、内存与实时性
```

通过流程图、示例和实践，把分散的知识串联起来，帮助学习者建立从传感器数据到产品行为的整体认识，并为进一步的专题学习提供入口。


## 适合人群

开发、产品和希望建立整体认识的学习者；

## 项目定位

这不是教材，也不是术语说明书，而是一条围绕数据流程展开的实践型学习路径。AI 负责协助整理内容，人工负责方向设定、补充和审核。

## 项目状态

主要用于个人学习、技术整理和原型探索。具体功能、安装方法和运行方式请查看各子项目目录中的说明文件。
